TDMod.Net is a research and modelling group website for sharing news, activities, models, publications, opportunities, and collaboration updates.

This starter site is set up as a classic academic news hub. The structure is intentionally simple so the group can publish short updates, maintain project pages, collect publication records, and announce ways to work together.
