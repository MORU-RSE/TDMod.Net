# Landing page drafts (archive)

Full-length drafts of the site landing pages, written 14 August 2026.

These are **not published**. Hugo only builds `content/`, and the Pages workflow
deploys `./public`, so nothing in `docs/` reaches the live site.

## Why this exists

The live landing pages were deliberately trimmed back to a short description
only. These longer versions are kept so the research and wording are not lost,
and so sections can be pulled back in later when there is real material to
support them.

## Worth keeping in mind

- `models.md` holds a linked list of 16 real network tools and repositories
  (MAEMOD R package, METCAP, Cambodia Outbreak Detection Tool, MARC Malaria
  Data Repository, and others). That list is the most reusable part of this
  archive — it is not currently on the live site.
- `about.md` names the lead of each research theme. The live page describes the
  themes without naming people.
- These drafts still use the phrase "Greater Mekong Subregion", which has since
  been removed from the live site in favour of "Southeast Asia".
- External links were checked on 14 August 2026 and were working then.
